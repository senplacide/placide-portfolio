## Featured Projects

### Student Scholarship & Academic Performance Analytics

An interactive Power BI dashboard analyzing student scholarship allocation, academic performance, campus differences, and scholarship-related risks. The project addresses the challenge of gaining a centralized view of scholarship distribution and student outcomes across multiple campuses.

**Tools:** Power BI, DAX, Power Query, Microsoft Excel

[View Case Study](https://senplacide.github.io/placide-portfolio/projects/scholarship-dashboard.html)

---

### AgriConnect — Agricultural Marketplace

A web application that translates an agricultural marketplace concept into a functional digital platform. AgriConnect connects agricultural products and users through a backend application, database, and REST API — addressing the gap in digital tools for presenting and managing agricultural marketplace information.

**Tools:** Node.js, Express.js, MongoDB, REST API, Cloudinary

[View Case Study](https://senplacide.github.io/placide-portfolio/projects/agriconnect.html)

---

### Hotel Performance Analytics

An executive Power BI dashboard analyzing hotel revenue, bookings, room utilization, and key hospitality KPIs including ADR and RevPAR across 2023–2025. The project brings together multiple performance dimensions to support management in evaluating hotel operations and identifying trends.

**Tools:** Power BI, DAX, Power Query, Microsoft Excel

[View Case Study](https://senplacide.github.io/placide-portfolio/projects/hotel-analysis.html)
